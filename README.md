# Yamato Chat V2.2 - Account Edition

Yamato Chatにアカウント機能を追加した版。

## 追加されたもの

- YDMログイン画面
- 新規登録画面
- 表示名
- ユーザー名（半角英数字 + `_`）
- パスワード
- ゲートパスワード
- 自己紹介
- 30日間のサーバー側セッション
- ログアウト
- プロフィール表示
- WebSocket接続をログイン済みアカウントに限定
- パスワードはbcryptでハッシュ化して保存
- 既存チャット履歴との互換性を維持

## 重要: 初回セットアップ

GitHubを更新する前後どちらでも構いませんが、Supabase SQL Editorで
`account_migration.sql` を1回実行してください。

RenderのEnvironment Variablesは既存の
`SUPABASE_URL`
`SUPABASE_SECRET_KEY`
をそのまま使います。

Secret KeyをGitHubやブラウザコードに入れないでください。

## 注意

ゲートパスワードは現在「YDMへのログイン時に必要な追加パスワード」として実装しています。
将来、作品ごとのゲートパスワードを別テーブルで追加できます。

## V2.2.1

- ログイン/新規登録画面のブランド表記を「Yamato Chat」に統一
- 登録・ログイン時にサーバーから返された具体的なエラーを画面に表示

## V2.2.2

- ゲートパスワードをアカウントごとのパスワードではなく、Yamato Chat全体で共通の1つに統一
- `YAMATO_GATE_PASSWORD` をRenderのEnvironment Variablesに設定して管理
- アカウントパスワードとは分離

### 共通ゲートパスワードの設定

Render の Environment Variables に次を追加してください。

- `YAMATO_GATE_PASSWORD` = 全員共通で使うゲートパスワード

これはアカウントごとには保存せず、Yamato Chat全体で1つだけ使います。

## V2.3

- プロフィールの表示名・自己紹介を編集
- プロフィールアイコンを画像アップロード
- チャットに画像・ファイル添付（最大20MB）
- 画像はチャット内にプレビュー表示
- Supabase Storage の `yamato-chat-files` バケットを起動時に自動作成
- チャットメッセージにもユーザーアイコンを表示

## V2.3.1 fixes

- ページを開くたびに明示的なログインを要求
- ログイン時の共通ゲートパスワードを必須
- アイコン変更時に既存メッセージの表示も即時更新
- `chat_users` のアイコン情報をプロフィール更新と同時に同期

## V2.3.2

- チャットの表示名をログイン用ユーザー名ではなくプロフィールの表示名に統一
- 既存の `chat_users` に `display_name` を追加し、`accounts` から既存ユーザーの表示名を同期
- 共通ゲートパスワードのログイン画面ラベル重複を修正

## V2.3.3

- ファイル添付をDiscord風のカード表示に変更
- HTMLなどのファイルをクリックしたときにチャット内でコード表示する挙動を廃止
- 通常ファイルはファイル名・容量・ダウンロードボタンを表示
- 画像は画像プレビュー＋ファイル名＋表示ボタン
- 表示名をチャット履歴・新規メッセージの両方で優先使用
- 共通ゲートパスワードの二重表記を修正

## V2.3.4

- 添付ボタンをメッセージ入力欄に正しく一体化
- クリップボードから画像/ファイルを貼り付けて添付できるように対応
- 添付前のプレビュー/取り消しUIを追加
- HTML等の通常ファイルはクリックでブラウザ表示せず、ダウンロードボタンから保存
- 画像はDiscord風のプレビューカード

## V2.3.5

- 画像添付の表示サイズを制限してチャット画面が崩れないように修正
- 画像プレビュー最大高さを300px（スマホ260px）に調整
- 画像の下にファイル名・容量・「表示」ボタンを常に配置
- 画像自体を押して勝手に開く挙動を避け、明示的な「表示」操作に統一

## V2.3.6

- 画像/ファイル送信後もメッセージ入力欄が常に画面下部に残るよう修正
- `.main` と `.messages` に `min-height: 0` を追加してFlexレイアウトの内容押し出しを防止
- 添付カードが入力欄を画面外へ押し出さないよう修正

## V2.3.7

- 日本語ファイル名の文字化けをサーバー側で修復
- UTF-8/Latin-1系の文字コード不一致による mojibake を添付保存前に正規化

## V2.4.0

- 自分が送信したメッセージだけ編集・削除可能
- 編集はメッセージ上の ✎ ボタンから実行
- 削除は 🗑 ボタン＋確認ダイアログ
- 編集済みメッセージには「(編集済み)」を表示
- サーバー側でも `user_id` と `channel_id` を検証して他人のメッセージを編集・削除できないようにした
- リアクション/絵文字機能は次段階へ
